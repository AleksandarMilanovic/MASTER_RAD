# Sistemski zahtevi

## Minimalni zahtevi za Fazu 1

- 64-bitni host sistem;
- najmanje 4 CPU jezgra dodeljena Docker okruženju;
- najmanje 8 GB RAM-a dodeljeno Docker okruženju;
- najmanje 50 GB slobodnog prostora;
- Docker Engine sa Compose plugin-om ili Docker Desktop;
- Git;
- Bash okruženje za pomoćne skripte.

## Preporučeni zahtevi za kompletno hibridno okruženje

- 8 ili više CPU jezgara;
- 32 GB RAM-a;
- najmanje 250 GB slobodnog SSD prostora;
- podrška za hardversku virtualizaciju;
- mogućnost pokretanja Windows i Linux virtuelnih mašina;
- izolovana laboratorijska mreža.

## Ograničenja

Minimalni zahtevi odnose se samo na Wazuh single-node i mali broj ciljnih sistema.
Active Directory, više Windows stanica, TheHive/Cortex i monitoring zahtevaju
dodatne resurse. Potrošnja će biti merena tokom projekta.
